# ТЗ «Дожми сегодня» — лист «Задание»

Источник: таблица `1-IMz283RylHMfqthH2Wl-aGPery_kxUT8ZvTIw7YObM`, лист «Задание».
Срок: 3 дня. Сегодня по заданию: **пятница, 13 ноября 2026 года**.

## Суть

Утром у менеджера 40 открытых сделок, дожать сегодня он успеет пять. Программа: загрузил выгрузку → увидел, какие 5 дожимать, в каком порядке и что сделать по каждой.

Сдаётся не список сделок, а программа. Она должна работать на другой выгрузке: другие клиенты, другой менеджер, другие слова в комментариях. **Программа должна разбираться в сделках, а не помнить эту таблицу.**

## Что есть

| | |
|---|---|
| Сделки | лист «Сделки»: 40 открытых сделок менеджера Алексея, клиенты придуманные |
| Правила | лист «Правила»: оплата, скидки, срок действия счёта, кто принимает решение |
| Сегодня | пятница, 13 ноября 2026 года |
| Цель | до плана месяца не хватает **1 550 000 ₽**; сегодня важны сделки, по которым **деньги придут быстрее всего** |

## Требования

1. Интерфейс любой: веб-страница (.html или ссылка), Telegram-бот, другой — лишь бы можно было показать в работе.
2. Вход: файл CSV (лист «Сделки» → Файл → Скачать → CSV) и дата «Сегодня». Дату не указали → текущая.
3. Ответ: 5 сделок по порядку. У каждой — номер, клиент, сумма и что сделать сегодня. Есть следующий шаг → показать его. Шага нет или он явно не подходит (например, срок уже прошёл) → писать «не уверен, что делать».
4. Последняя строка ответа: номера выбранных сделок через запятую, например «Итог: 2, 5, 7, 8, 4».
5. Сделки выбирает сама программа по своим правилам. Во время работы она не спрашивает нейросеть.

## Что прислать

1. Программу: .html, ссылка, Telegram-бот или запись экрана.
2. Ссылку на чат с нейросетью, если делали с ней.
3. Голосовое до 3 минут про программу: по каким признакам выбирает сделки, почему такой порядок, где может ошибиться.
4. Голосовое до 3 минут про опыт в продажах: что и кому продавали, срок, план, одна дожатая сделка.

## Чек-лист приёмки (как я его понял)

- [ ] Читает CSV этого листа без правок: 10 колонок, `Сумма, ₽` с неразрывными пробелами, даты `дд.мм.гггг`.
- [ ] Шаг берётся из «Комментарий менеджера», когда отдельной колонки шага нет.
- [ ] Дубли (№1 = №12) не занимают два места в пятёрке.
- [ ] Мёртвые сделки не предлагаются: №9 купили у конкурента, №34 деньги уже пришли.
- [ ] Отложенные на месяцы не попадают в пятёрку: №23 март 2027, №26 аукцион в декабре.
- [ ] Просроченный шаг → «не уверен, что делать», а не «сделай этот шаг».
- [ ] Правила компании применяются: счёт 5 рабочих дней, скидка ≤7%, предоплата, ЛПР, сроки изготовления/доставки.
- [ ] Порядок = скорость прихода денег, а не только «просрочено/большая сумма».
- [ ] Последняя строка — «Итог: номера, через запятую».
- [ ] Ни одного обращения к нейросети в рантайме.
